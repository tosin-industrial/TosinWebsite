騰信官網靜態重建報告（static-rebuild 分支）
==========================================
本檔案合併到 main 前請刪除。
（檔名以底線開頭，GitHub Pages 的 Jekyll 預設不會發布它，但仍建議刪除。）


一、新結構
----------
build.py                  產生器，只用 Python 標準函式庫。執行 python build.py
                          → 產生 30 個 */index.html 與 sitemap.xml（路徑與原本完全相同）
                          連跑兩次結果相同（第二次顯示「0 個檔案有變動」）。
src/layout/site.json      全站設定：中英選單、頁首頁尾的中英文字、GA4 編號、email
src/layout/layout.html    共用版型：<head>、頁首、手機側選單、搜尋框、頁尾、回到頂端
src/pages/**.html         每頁一檔（30 檔），檔名對應網址，例如
                            src/pages/products/o-ring.html       → /products/o-ring/
                            src/pages/zh/products-zh/o-ring-zh.html → /zh/products-zh/o-ring-zh/
                          檔案開頭 <!--page {...} --> 是該頁設定（JSON）：
                            url、lang（en/zh）、title、hreflang（en/zh/x-default 三個完整網址）、
                            body_class、carousel（true 才載入輪播程式）、scripts（額外載入的外部 JS，例如 fslightbox）
                          接著可有一段 <style data-page-css>（該頁專屬樣式，原 Elementor 產生），其後是正文。
assets/css/site.css       Blocksy 主題＋Elementor 核心樣式（精簡後）
assets/css/widgets.css    Elementor 元件樣式、進場動畫、Swiper、字型、原本延遲載入的樣式（精簡後）
assets/css/no-scripts.css 瀏覽器關閉 JS 時用（原樣保留）
assets/fonts/             14 個字型檔（原 66 個，只留網站實際用到的字元範圍）
assets/js/site.js         自寫小程式（約 12KB），取代 jQuery、jquery-migrate、jquery-ui、
                          Elementor frontend／webpack、Blocksy main.js
assets/vendor/swiper/     Swiper 8.4.5（原 Elementor 內附版本），只在首頁、設備頁中英共 4 頁載入
wp-content/uploads/...    30 頁實際引用的 73 個圖檔，路徑不變
tools/                    一次性工具（重建時用，平常不必執行）：
                            extract.py         從舊 HTML 抽出內容
                            build_css.py       合併精簡 CSS
                            compress_images.py 壓縮大圖
                            verify.py          檢查工具（見第三節），以後改完網站也可以跑
                            kit.css            build_css.py 需要的 Elementor 全站樣式片段
                          extract.py、build_css.py 需要舊網站檔案，用法：
                            git worktree add ../old main   （或任何 main 時期的 checkout）
                            python tools/build_css.py ../old

site.js 處理的互動（逐一盤點原 Blocksy／Elementor 實際用到的功能）：
  1. 手機版側選單（offcanvas）開關：漢堡鈕開、X 鈕／點背景／Esc 關，開啟時鎖住頁面捲動
  2. 搜尋視窗開關（開啟時自動聚焦輸入框）
  3. 手機選單「產品」子選單展開／收合
  4. 桌機選單「產品」下拉：滑鼠移入、鍵盤 Tab 都會展開；超出視窗右緣自動改往左
  5. 回到頂端按鈕：捲動超過 300px 出現（與原 Blocksy 相同），手機版照原樣隱藏
  6. Elementor 進場動畫：用 IntersectionObserver 捲到才淡入；JS 沒跑或使用者設定減少動態時直接顯示，
     另有 3 秒保險機制，不會永遠隱形
  7. 圖片輪播：依 Elementor 原設定（每頁張數、手機／平板張數、間距、自動播放 5 秒、滑鼠移入暫停、
     箭頭、圓點、無限循環）換算成 Swiper 參數，斷點換算方式照抄 Elementor
  語言切換、Sticky header：原網站沒有 sticky header；語言切換是一般連結（國旗），不需要 JS。
  fslightbox 燈箱（jsDelivr）、聯絡頁 Google 地圖 iframe、speculationrules、GA4 都照原樣保留。


二、以後怎麼改
--------------
改選單：只改 src/layout/site.json 的 languages.en.menu／languages.zh.menu，然後 python build.py。
        桌機選單、手機選單、頁尾選單三處會同時更新；目前頁面的反白會自動判斷。
        新增項目的 id 隨便填一個沒用過的數字（只用來產生 CSS class）。
改頁首頁尾文字（地址、電話標題、口號等）：src/layout/site.json 的 t 區塊。
改某頁內容：改 src/pages/ 下對應的檔案，再 python build.py。不要直接改根目錄的 index.html，
        下次 build 會被覆蓋。
新增一頁：
  1. 複製一個相似的頁面檔（例如 src/pages/products/o-ring.html）成新檔名
  2. 改開頭設定的 url、title、hreflang（中英兩頁要互相指向，x-default 指英文版）、
     body_class 裡的 page-id-數字 與 elementor-page-數字（給新頁一個沒用過的數字，例如 9001）
  3. 改正文；若沿用別頁的 <style data-page-css>，裡面的 .elementor-數字 要跟著改成新數字
  4. 需要的話在 site.json 選單加上新頁
  5. python build.py（sitemap.xml 會自動加入新頁），再 python tools/verify.py 檢查
注意：CSS 已刪掉目前 30 頁用不到的規則。若新頁用到原網站沒用過的 Elementor 元件
     （例如手風琴、分頁籤、表單），樣式會缺，需要另外補 CSS。原始 CSS 在 main 分支的 git 歷史裡。

四、已知差異（全部列出）
------------------------
1. 【有意修正】目前頁面在選單裡的連結：舊版 HTTrack 把「目前所在頁」的選單連結改成 "/"，
   例如在 O-Ring 頁點選單的 O-Ring 會跳回首頁；中文首頁的 logo 與「首頁」也指到英文首頁 "/"。
   新版改成指向該頁自己（中文首頁指向 /zh/）。這是 verify.py 連結清單裡唯一的差異。
2. 站內連結從相對路徑（../about-us/）改成站根路徑（/about-us/），解析後的網址相同。
   影響：直接雙擊 HTML 檔用 file:// 開啟時連結與圖片不會正確（舊版其實也不完全正確），
   本機預覽請用 http 伺服器，例如在 repo 根目錄執行 python -m http.server 8000。
3. 刪掉的 WordPress 遺留標記：每頁 <head> 的 WordPress 預設樣式變數、gmpg profile 連結、
   fonts.googleapis 的 dns-prefetch、HTTrack 註解、jQuery／Elementor／Blocksy 的設定 script；
   正文裡的 data-e-action-hash 屬性（Elementor 燈箱用，內含本機 WordPress 主機名 tosinstatic.local）。
4. 頁尾 email 的防垃圾信編碼：原本 WordPress 每次隨機編碼，現在固定為全部轉成 HTML 實體，
   顯示與點擊結果相同。
5. 燈箱：原本點圖可能同時觸發 Elementor 自帶燈箱與 fslightbox，現在只剩 fslightbox。
6. 頁面專屬樣式的載入位置：原本夾在 Elementor 核心樣式與元件樣式之間，新版維持同樣順序
   （site.css → 頁面樣式 → widgets.css）；原本延遲載入的 Blocksy 樣式改為一開始就載入。
7. 任務說明要刪除 wp-content/uploads/elementor，但輪播縮圖放在
   wp-content/uploads/elementor/thumbs/（8 張，被首頁／設備頁引用），為了「路徑不變、圖片不壞」
   保留這 8 張，其餘（字型、CSS）已刪。
